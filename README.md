# Telegram iOS UI Kit — Android app

این پروژه ظاهر **Telegram iOS UI Kit (Community)** را از روی اسکرین‌شات‌هایی که کاربر فرستاده، با کد بازسازی می‌کند و خروجی نهایی آن یک **APK اندروید** است.

## وضعیت فعلی

- نسخه‌ی ۲: رابط کاربری iOS بازسازی شده و برای مقایسه روی گوشی نصب می‌شود.
- صفحه‌ها: Chats، چت‌ها (Cat، Digital Nomads، Dog، Dolphin، Pavel Durov، Wallet، Catch News)، Contacts، Calls، Search، Archived، پروفایل‌ها و Settings.
- هنوز به سرور وصل نیست؛ ثبت‌نام/لاگین و پیام‌رسانی واقعی بین کاربران همین اپ، مرحله‌ی بعد از تأیید نهایی ظاهر است.
- فهرست اسکرین‌شات‌های مرجع در `design/INVENTORY.md` ثبت شده است. مبنای طراحی فقط همان اسکرین‌شات‌های iOS ارسالی کاربر است.

## نصب روی گوشی

1. از بخش **Releases** همین مخزن، آخرین فایل `Telegram-UI-Kit.apk` را دانلود کنید.
2. فایل APK را روی گوشی باز کنید و **Install / نصب** را بزنید.
3. اگر اندروید اجازه خواست، برای مرورگر یا فایل‌منیجر گزینه‌ی نصب از منبع ناشناس را فعال کنید.
4. اگر نسخه‌ی قبلی نصب است و نصب نسخه‌ی جدید خطا داد، اول نسخه‌ی قبلی را حذف کنید و بعد APK جدید را نصب کنید. دلیلش امضای Debug متفاوت در بیلدهای خودکار است.

حداقل نسخه‌ی اندروید: **Android 8 (API 26)**.

## ساختار

```text
app/src/main/assets/   رابط کاربری (HTML/CSS/JS و تصاویر بریده‌شده از مرجع)
app/src/main/java/     MainActivity برای نمایش رابط داخل WebView
.github/workflows/     ساخت خودکار APK در GitHub Actions
design/INVENTORY.md    فهرست فریم‌ها و دسته‌های اسکرین‌شات مرجع
```

این پروژه یک بازسازی غیررسمی از رابط کاربری است و ارتباطی با شرکت Telegram ندارد.
